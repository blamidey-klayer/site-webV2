# Klayer · site web v2

Page d'accueil « entreprise » de Klayer, construite sur la structure d'une page de cas d'usage entreprise (hero centré, scène animée, sections éditoriales, appel à l'action final, grand pied de page).

- Textes : `src/content.ts`, repris du deck « Klayer · Présentation 2026 · V2 » et du Doc « Klayer · Messaging du deck ».
- Charte : tokens du Klayer · Design system (`src/app/globals.css`), glyphes officiels dans `public/`.
- Pile : Next.js 16, React 19, Tailwind CSS 4, Framer Motion.

```bash
npm install
npm run dev
```
